# Phi-4-mini-instruct

### Microsoft's compact, capable instruction-following model

Phi-4-mini-instruct is Microsoft's latest small language model, delivering impressive reasoning and instruction-following in a package optimized for on-device and edge deployment. High capability, minimal resource requirements.
